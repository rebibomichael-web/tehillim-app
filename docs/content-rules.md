## 1. Important: what exists and what doesn't

There is **no automatic name-entry feature** in what was built. Each booklet was produced by hand-editing a copy of the text source. Nothing converts English names to Hebrew, and nothing splits a name into letters by code. Sections 2 and 5 below describe the rules that were applied by hand, written so you can implement them in an app.

---

## 2. What changes when a name is used

Only these parts change; everything else is fixed text.

1. **Cover**: `לְעִלּוּי נִשְׁמַת` followed by the full name with nikud, e.g. `בֵּילָא בְּרָכָה בַּת מֹשֶׁה דָּוִד`.
2. **Section ג — Psalm 119, letters of the name**: one 8-verse stanza of Psalm 119 per letter of the deceased's name **and** the parent's name, in order, including the connector בן/בת.
   - David: דוד יעיש בן יוסף → ד ו ד · י ע י ש · ב נ · י ו ס פ (13 stanzas, includes בן and the father's name).
   - Bila Bracha: built as ב י ל א ב ר כ ה (her own name only, no בת/father). **Inconsistent with David's**, which included בן and the father's name. Decide one rule for the app.
3. **Section ד — נְשָׁמָה**: always the same four stanzas, נ ש מ ה. Never changes.
4. **El Malei Rachamim**: name inserted after `אֶת נִשְׁמַת`; grammar switched by gender:
   - male: שֶׁהָלַךְ לְעוֹלָמוֹ … נִשְׁמָתוֹ … מְנוּחָתוֹ … יַסְתִּירֵהוּ … נַחֲלָתוֹ … וְיָנוּחַ … מִשְׁכָּבוֹ
   - female: שֶׁהָלְכָה לְעוֹלָמָהּ … נִשְׁמָתָהּ … מְנוּחָתָהּ … יַסְתִּירֶהָ … נַחֲלָתָהּ … וְתָנוּחַ … מִשְׁכָּבָהּ
5. **Leaving the grave**: male תִּשְׁכַּב בְּשָׁלוֹם / female תִּשְׁכְּבִי בְּשָׁלוֹם (also in the contents list).
6. **Pebble prayer (יְהִי רָצוֹן)**: name inserted; מְנוּחָתוֹ/זְכוּתוֹ → מְנוּחָתָהּ/זְכוּתָהּ for a woman. David's version included the mother (בֶּן יוֹסֵף וְאֶסְתֵּר); Bila Bracha's has the father only because only his name was given.
7. **Section א, ב, ו** and the Ata Gibor passage: never change.

### Letter rules (applied by hand)
- **Nikud is ignored** for letter selection (בֵּילָא → ב י ל א).
- **Final letters map to regular letters**: ך→כ, ם→מ, ן→נ, ף→פ, ץ→צ.
- **Spaces are skipped.**
- **Repeated letters repeat the stanza** (ב appears twice in בילא ברכה, so the ב stanza appears twice).
- **בן/בת**: in David's booklet, included as letters (ב נ). In Bila Bracha's, the name section stopped before בת. Pick one convention.

### א · בַּכְּנִיסָה לְבֵית הָעָלְמִין [On entering the cemetery — said at its edge, before approaching the graves, if you have not seen Jewish graves in 30 days]

בָּרוּךְ אַתָּה ה׳ אֱלֹהֵינוּ מֶלֶךְ הָעוֹלָם, אֲשֶׁר יָצַר אֶתְכֶם בַּדִּין, וְזָן אֶתְכֶם בַּדִּין, וְכִלְכֵּל אֶתְכֶם בַּדִּין, וְהֵמִית אֶתְכֶם בַּדִּין, וְיוֹדֵעַ מִסְפַּר כֻּלְּכֶם בַּדִּין, וְהוּא עָתִיד לְהַחֲיוֹתְכֶם וּלְקַיֵּם אֶתְכֶם בַּדִּין. בָּרוּךְ אַתָּה ה׳, מְחַיֵּה הַמֵּתִים.

אַתָּה גִּבּוֹר לְעוֹלָם אֲדֹנָי, מְחַיֵּה מֵתִים אַתָּה, רַב לְהוֹשִׁיעַ. [[בחורף]] מַשִּׁיב הָרוּחַ וּמוֹרִיד הַגֶּשֶׁם. [[בקיץ]] מוֹרִיד הַטָּל. מְכַלְכֵּל חַיִּים בְּחֶסֶד, מְחַיֵּה מֵתִים בְּרַחֲמִים רַבִּים, סוֹמֵךְ נוֹפְלִים, וְרוֹפֵא חוֹלִים, וּמַתִּיר אֲסוּרִים, וּמְקַיֵּם אֱמוּנָתוֹ לִישֵׁנֵי עָפָר. מִי כָמוֹךָ בַּעַל גְּבוּרוֹת וּמִי דּוֹמֶה לָּךְ, מֶלֶךְ מֵמִית וּמְחַיֶּה וּמַצְמִיחַ יְשׁוּעָה. וְנֶאֱמָן אַתָּה לְהַחֲיוֹת מֵתִים.

וְֽיֶעֱשָֽׁנוּ׃ אָשִׁירָה לַה׳ בְּחַיָּי אֲזַמְּרָה לֵאלֹהַי בְּעוֹדִֽי׃ יֶעֱרַב עָלָיו שִׂיחִי אָנֹכִי אֶשְׂמַח בַּה׳׃ יִתַּמּוּ חַטָּאִים ׀ מִן־הָאָרֶץ וּרְשָׁעִים ׀ עוֹד אֵינָם בָּרֲכִי נַפְשִׁי אֶת־ה׳ הַֽלְלוּ־יָֽהּ׃


**תְּהִלִּים · פֶּרֶק ק״ל [Psalm 130]**


שִׁיר הַֽמַּעֲלוֹת מִמַּעֲמַקִּים קְרָאתִיךָ ה׳׃ אֲדֹנָי שִׁמְעָה בְקוֹלִי תִּהְיֶינָה אָזְנֶיךָ קַשֻּׁבוֹת לְקוֹל תַּחֲנוּנָֽי׃ אִם־עֲוֺנוֹת תִּשְׁמָר־יָהּ אֲדֹנָי מִי יַעֲמֹֽד׃ כִּֽי־עִמְּךָ הַסְּלִיחָה לְמַעַן תִּוָּרֵֽא׃ קִוִּיתִי ה׳ קִוְּתָה נַפְשִׁי וְֽלִדְבָרוֹ הוֹחָֽלְתִּי׃ נַפְשִׁי לַֽאדֹנָי מִשֹּׁמְרִים לַבֹּקֶר שֹׁמְרִים לַבֹּֽקֶר׃ יַחֵל יִשְׂרָאֵל אֶל־ה׳ כִּֽי־עִם־ה׳ הַחֶסֶד וְהַרְבֵּה עִמּוֹ פְדֽוּת׃ וְהוּא יִפְדֶּה אֶת־יִשְׂרָאֵל מִכֹּל עֲוֺנֹתָֽיו׃



### ג · תְּהִלִּים קי״ט — אוֹתִיּוֹת הַשֵּׁם [Psalm 119 · letters of the name]

**Letter ו**

### ה · אֵל מָלֵא רַחֲמִים [El Malei Rachamim]

אֵל מָלֵא רַחֲמִים שׁוֹכֵן בַּמְּרוֹמִים, הַמְצֵא מְנוּחָה נְכוֹנָה עַל כַּנְפֵי הַשְּׁכִינָה, בְּמַעֲלוֹת קְדוֹשִׁים וּטְהוֹרִים כְּזֹהַר הָרָקִיעַ מַזְהִירִים, אֶת נִשְׁמַת הָרַב דָּוִד יָעִישׁ בֶּן יוֹסֵף שֶׁהָלַךְ לְעוֹלָמוֹ, בַּעֲבוּר שֶׁנָּדַבְנוּ צְדָקָה בְּעַד הַזְכָּרַת נִשְׁמָתוֹ, בְּגַן עֵדֶן תְּהֵא מְנוּחָתוֹ. לָכֵן בַּעַל הָרַחֲמִים יַסְתִּירֵהוּ בְּסֵתֶר כְּנָפָיו לְעוֹלָמִים, וְיִצְרֹר בִּצְרוֹר הַחַיִּים אֶת נִשְׁמָתוֹ, ה׳ הוּא נַחֲלָתוֹ, וְיָנוּחַ בְּשָׁלוֹם עַל מִשְׁכָּבוֹ, וְנֹאמַר אָמֵן.



### ו · עַל הַמַּצֵּבָה [Place your left hand on the monument and recite]

וְנָחֲךָ ה׳ תָּמִיד וְהִשְׂבִּיעַ בְּצַחְצָחוֹת נַפְשֶׁךָ, וְעַצְמֹתֶיךָ יַחֲלִיץ, וְהָיִיתָ כְּגַן רָוֶה וּכְמוֹצָא מַיִם אֲשֶׁר לֹא יְכַזְּבוּ מֵימָיו: וּבָנוּ מִמְּךָ חָרְבוֹת עוֹלָם, מוֹסְדֵי דוֹר־וָדוֹר תְּקוֹמֵם, וְקֹרָא לְךָ גֹּדֵר פֶּרֶץ מְשׁוֹבֵב נְתִיבוֹת לָשָׁבֶת.


**כְּשֶׁיּוֹצְאִים מִן הַקֶּבֶר אוֹמְרִים [As you leave the grave, say]**


תִּשְׁכַּב בְּשָׁלוֹם עַד בֹּא מְנַחֵם מַשְׁמִיעַ שָׁלוֹם.



### ז · הֲנָחַת אֶבֶן [Place a pebble on the grave, then say]

יְהִי רָצוֹן שֶׁתְּהֵא מְנוּחָתוֹ שֶׁל הָרַב דָּוִד יָעִישׁ בֶּן יוֹסֵף וְאֶסְתֵּר פֹּה בְּכָבוֹד וּזְכוּתוֹ יַעֲמוֹד לִי.

## 5. English → Hebrew names, pinch-zoom, font resizing

**English → Hebrew:** not implemented. Both names were given in Hebrew (David's in the uploaded file, Bila Bracha's from a handwritten note, which I transcribed and added nikud to). Automatic transliteration of names is unreliable (one English spelling can map to several Hebrew spellings), so an app should ask for the Hebrew name directly, or offer a short list of Hebrew spellings for the user to confirm.

**Pinch-zoom:** turned off on purpose (`<meta name="viewport" content="width=device-width, initial-scale=1, maximum-scale=1, user-scalable=no">`). Browser pinch-zoom enlarges the whole page and forces sideways scrolling, which the user didn't want. There is **no custom pinch gesture**.

**Font resizing:** two buttons (א− / א+) fixed at the bottom-left. Every font size is `calc(Npx * var(--fs))`. Each tap changes `--fs` by 0.1, from 0.6 to 2.4, and saves it in localStorage (`thl-fs`) so it's remembered next time. Text re-wraps to the screen width, so scrolling stays vertical.

```html
<script>
(function(){
  var fs = 1;
  try { fs = parseFloat(localStorage.getItem('thl-fs')) || 1; } catch(e){}
  function apply(){
    document.body.style.fontSize = (18*fs) + 'px';
    document.documentElement.style.setProperty('--fs', fs);
    try { localStorage.setItem('thl-fs', fs); } catch(e){}
  }
  function step(d){ fs = Math.min(2.4, Math.max(0.6, +(fs + d).toFixed(2))); apply(); }
  document.getElementById('plus').addEventListener('click', function(){ step(0.1); });
  document.getElementById('minus').addEventListener('click', function(){ step(-0.1); });
  apply();
})();
</script>
```

The full phone HTML is `tehillim-mobile-src.html` in this package (readable) and `Tehillim Phone.html` (bundled, offline).
