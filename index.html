שם האב או שם האם?

אשכנזים: שם האב. לפי גשר החיים (ח״א פרק ל״א), אשכנזים מזכירים את הנפטר בשם אביו.

ספרדים: שם האם. ספרדים מזכירים בשם אמו, על פי הזוהר (כף החיים או״ח רפ״ד:ל״ז).

שני ההורים: יש קהילות המזכירות את שניהם (בצל החכמה ח״ג צ״א).

לפרק קי״ט עצמו, גשר החיים מביא רק את אותיות שם הנפטר ואותיות נשמה. לכן כל אפשרות כאן כשרה; נהגו כמנהג משפחתכם.

Father's or mother's name?

Ashkenazim: father's name. Gesher HaChaim (I:31) says Ashkenazim name the deceased with the father's name.

Sephardim: mother's name. Sephardim use the mother's name, based on the Zohar (Kaf HaChaim 284:37).

Both parents: some communities name both (Betzel HaChochma III:91).

For Psalm 119 itself, Gesher HaChaim lists only the letters of the name and נשמה. So any option here is fine; follow your family's custom.
